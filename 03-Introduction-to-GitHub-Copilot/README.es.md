# Introducción a GitHub Copilot

En este módulo de aprendizaje, nos sumergiremos en el revolucionario panorama de la programación en pareja con IA usando GitHub Copilot, la primera herramienta de desarrollador con IA a gran escala diseñada para mejorar tu experiencia de codificación.

GitHub Copilot analiza el contexto de archivos y comentarios y la entrada de su chat interactivo para proporcionar sugerencias de autocompletado, permitiéndote escribir código más rápido y con menos esfuerzo. A medida que profundizas en este módulo, desentrañarás las complejidades de GitHub Copilot, explorando sus capacidades en VS Code y Codespaces.

Nuestros objetivos de aprendizaje son ambiciosos, pero alcanzables. Al final del módulo, no solo serás capaz de articular qué es GitHub Copilot y sus ventajas, sino también comprenderás su disponibilidad para individuos y empresas. Obtén información sobre el futuro de GitHub Copilot y sumérgete en ejercicios prácticos para dominar su utilización con Visual Studio Code.

Como la investigación ha demostrado, GitHub Copilot capacita a los desarrolladores para codificar más rápido, enfocarse en resolver problemas sustanciales, mantener períodos más largos de productividad y experimentar mayor satisfacción en su trabajo.

Nota: Aunque este módulo usa [Codespaces](https://github.com/codespaces), puedes usar GitHub Copilot en una variedad de otros entornos, incluyendo localmente con Visual Studio Code.

</header>

- **¿Para quién es esto?:** Desarrolladores, Ingenieros DevOps, Gerentes de desarrollo de software, Testers.
- **Lo que aprenderás:** Cómo instalar Copilot en un Codespace, aceptar sugerencias de código, aceptar sugerencias de comentarios.
- **Lo que construirás:** Archivos Javascript que tendrán código generado por la IA de Copilot para sugerencias de código y comentarios.
- **Prerrequisitos:** Para usar GitHub Copilot, debes tener una suscripción activa de GitHub Copilot. Regístrate para Copilot Free para VS Code [Copilot for free para VS Code](https://learn.microsoft.com/en-us/visualstudio/ide/copilot-free-plan?view=vs-2022).
- **Tiempo:** Este curso puede completarse en menos de una hora.

Al final de este módulo, serás capaz de:

- Explicar qué es GitHub Copilot y las ventajas que ofrece.
- Entender la disponibilidad de GitHub Copilot para individuos y empresas.
- Discutir el futuro de GitHub Copilot.
- Aprender cómo empezar a usar GitHub Copilot y algunas configuraciones comunes.
- Desarrollar usando GitHub Copilot con Visual Studio Code a través de ejercicios prácticos.
