<h1 align="center"> Dominando GitHub Copilot para Programación en Pareja</h1>

<h5 align="center">Revisión para Español Latinoamericano @paulanunes85 - 2025</h5>

Un curso de 8 lecciones que enseña todo lo que necesitas saber sobre cómo aprovechar GitHub Copilot como recurso de Programación en Pareja con IA.

Desbloquea el poder de la codificación colaborativa con nuestro plan de estudios integral sobre Dominando GitHub Copilot para Programación en Pareja. Este programa de vanguardia integra perfectamente la asistencia de codificación impulsada por IA a través de GitHub Copilot, capacitando a los estudiantes para acelerar sus habilidades de codificación junto con un compañero. A lo largo de 10 horas estimulantes, los participantes navegarán por procedimientos esenciales de configuración, aprovechando Visual Studio Code y GitHub Copilot Chat para la colaboración en tiempo real. Sumérgete en la autocompletación de GitHub Copilot, características personalizables y técnicas avanzadas de programación, todo mientras abrazas algoritmos impulsados por IA. Desde el manejo de errores hasta las pruebas unitarias, este plan de estudios está diseñado para inculcar las mejores prácticas y mejorar la calidad del código. Sumérgete en una experiencia de aprendizaje transformadora que fusiona la tecnología de IA más reciente con estrategias de programación en pareja, equipándote con las herramientas necesarias para el éxito en el dinámico panorama del desarrollo de software actual.

> [Ver el índice completo del curso en español](./INDICE.md)

## 🌱 Empezando

Para comenzar, asegúrate de seguir las instrucciones sobre cómo hacer un fork de las lecciones a tu propia cuenta de GitHub para poder modificar cualquier código y completar los desafíos. También puedes marcar este curso como favorito para encontrarlo más fácilmente después.

A continuación encontrarás los enlaces a cada lección. ¡Siéntete libre de explorar y comenzar con cualquier lección que más te interese!
